# R8 아키텍처 개요

> 이 문서는 R8의 설계 사상을 요약한다. 와이어 포맷은 `0001-wire-format-v0.1.md`가 유일한 기준(source of truth)이다.

## 1. 문제 정의

IPv4/IPv6 주소는 "누구인가(신원)"와 "어디 있는가(위치)"가 하나의 값에 결합되어 있다. 그 결과:

- 장치가 네트워크를 이동하면 주소가 바뀌고 연결이 끊긴다
- 하나의 연결에서 여러 회선을 동시에 쓰기 어렵다
- 출발지 위조·DDoS에 대한 기본 방어가 프로토콜에 없다
- 고정 주소가 사용자 추적 수단이 된다

R8은 이 문제를 네트워크 계층에서 다루는 실험적 설계다. 선행 기술(LISP/HIP의 식별자-위치 분리, QUIC의 연결 이동·주소 검증, Multipath QUIC, SRv6/SCION의 경로 프로그래밍, DetNet의 복제 전송)의 사상을 하나의 L3 프로토타입으로 재조합하는 것이 목표다.

## 2. 주소 역할의 분리

| 요소 | 크기 | 역할 | 변화 빈도 |
|---|---|---|---|
| EID (Endpoint Identity) | 128b | 장치·서비스의 논리적 신원 | 느림 (Service EID) / 세션마다 회전 (Private EID) |
| LOC (Routing Locator) | 128b | 현재 연결된 네트워크 위치 | 이동·장애 시 변경 |
| SCID (Session Context ID) | 64b | 세션 상태 참조 키 | 세션마다 |
| Path Token | 64~128b | 정책이 연결된 경로 지시자 | 경로 정책마다 |

- 데이터 패킷에는 EID를 싣지 않는다. 최초 OPEN에서 EID·암호 정보를 교환하고, 이후에는 48바이트 헤더의 SCID로 참조한다.
- EID→LOC 매핑은 서명된 레코드로 관리한다(만료 시각 포함). 매핑 인프라의 운영 주체·조회 경로는 **미해결 과제**로 명시한다 — LISP/ALT/DDT가 막혔던 지점이며 R8도 같은 문제를 갖는다.

## 3. 계층 분리 원칙

- 네트워크 계층(R8): 경로 집합 제공, 로케이터 전달, 첫 홉 검증.
- 전송 계층: 혼잡제어, 재전송, 패킷 분배.
- 코어 라우터에는 플로우별 상태를 두지 않는 것을 목표로 한다. SCID 상태는 가능하면 종단과 첫 홉에 국한한다. (설계 긴장점: SCID 조회 자체가 상태를 요구하므로, 어디까지가 허용 가능한 상태인지가 실험 질문 중 하나다.)

## 4. 보안 모델

- 서버는 발신자 주소를 검증하기 전까지 상태를 만들지 않는다 (VERIFY_COOKIE).
- 세션 수립 시에만 공개키 연산, 데이터 패킷에는 대칭 AEAD.
- 알고리즘은 협상 대상이며 고정하지 않는다. PQ 하이브리드(예: X25519+ML-KEM)를 기본 후보로 둔다.
- 출발지 인증이 대역폭 고갈형 DDoS를 막지는 못한다는 한계를 인정한다.

## 5. 이동성과 멀티패스

- 세션은 LOC가 아니라 EID/SCID에 묶인다. 위치 변경은 LOC_UPDATE로 통지하고 세션은 유지한다.
- 하나의 세션에 여러 경로를 등록하고 정책(FASTEST / BALANCED / CHEAPEST / REDUNDANT / TRUSTED / OFFLINE_SAFE)을 선택한다.
- Profile 3(고신뢰 복제)은 동일 패킷을 물리적으로 분리된 두 경로로 복제하고 수신측이 선도착 채택·중복 폐기한다. 관리 도메인 내부에서만 보장하며 공용 인터넷 전체의 지연 보장을 주장하지 않는다.

## 6. 전환 모델 (참고)

1. IPv4/IPv6 위 UDP 캡슐화 (udp-binding)
2. 통제 도메인(데이터센터·공장망) 내 네이티브
3. 경계 게이트웨이로 기존 단말 수용
4. 네이티브 확대

현실 경고: 1단계에서 이미 대부분의 가치를 얻으면 2~4단계로 갈 인센티브가 사라진다는 것이 IPv6 전환사의 교훈이다. R8 실험의 목적은 네이티브 승격이 아니라 **가설 검증**이며, 이 저장소의 성공 기준도 검증 데이터의 확보다.

## 7. 선행 기술과의 관계 (면책)

R8은 다음을 대체한다고 주장하지 않는다.

- QUIC / Multipath QUIC: 연결 이동·주소 검증·멀티패스를 전송 계층에서 이미 제공
- SCION: 도메인 간 path-aware 라우팅과 PKI 기반 신뢰 모델을 실배포 중
- HIP / LISP / ILNP / SHIM6: 식별자-위치 분리의 선행 설계
- RPKI/ROV, BCP 38: 출발지 위조 방어의 현실적 배포 경로

R8의 실험 가치는 이 사상들을 L3에서 통합했을 때의 정량적 이득(전환 시간, 손실률, 핸드셰이크 비용)을 측정하는 데 있다.
